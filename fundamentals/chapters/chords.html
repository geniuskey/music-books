Chapter 08

화음의 구조

세 개 이상의 음이 동시에 울리면 화음이 됩니다. 12개 피치 클래스에서 3개를 고르는 방법만 220가지인데, 악보와 코드 차트에 실제로 등장하는 이름은 몇십 개뿐입니다. 이 장에서는 화음을 3도를 쌓은 구조로 만들고, 전위와 보이싱이라는 '같은 집합을 공간에 배치하는 방법'으로 소리를 바꾸고, 화음 이름 붙이기를 탐색과 점수 매기기 문제로, 화음의 분류를 집합의 동치류로 다룹니다.

  • 3도 쌓기로 4가지 3화음과 주요 7화음을 만들고, 장3도·단3도의 조합으로 각 화음의 품질을 설명한다.
  • 전위와 숫자저음(6, 6/4, 6/5, 4/3, 4/2), 슬래시 코드 표기를 읽고 쓴다.
  • 9·11·13 텐션의 사용 가능 여부를 '화음음 위 단9도' 규칙으로 판정하고, 텐션 조합이 암시하는 음계를 찾는다.
  • 클로즈·오픈·드롭 2·드롭 3·셸·루트리스 보이싱을 만들고, 저음역 음정 한계를 임계대역으로 설명한다.
  • 화음 인식을 후보 탐색+점수 문제로 이해하고, 기본형과 포르테 번호를 계산해 220개의 3음 집합이 12개의 집합류로 묶이는 것을 확인한다.

3도를 쌓는다

서양 조성 음악의 화음은 대부분 3도 쌓기(Tertian Harmony)로 만들어집니다. 음계 위에서 한 칸씩 건너뛰며 음을 고르면(1·3·5·7…번째 음) 이웃한 음 사이가 항상 3도가 됩니다. 다이아토닉 음계의 3도는 장3도(4반음) 아니면 단3도(3반음)이므로(7장의 마이힐 성질), 화음의 '종류'는 이 두 크기의 순열로 결정됩니다.

$$\text{3화음} = (r,\ r+a,\ r+a+b),\quad a,b \in \{3,4\} \;\Rightarrow\; 2^2 = 4 \text{ 종류}$$
\(a\): 근음–3음, \(b\): 3음–5음(반음 수). 7화음은 3도를 하나 더 쌓아 \(2^3 = 8\)가지 중 7가지를 쓴다(4+4+4는 12반음으로 근음의 옥타브와 겹쳐 7화음이 되지 않음).

전위와 숫자저음, 슬래시 코드

화음의 구성음이 같아도 가장 낮은 음(베이스)이 무엇이냐에 따라 소리의 안정감이 크게 달라집니다. 근음이 베이스면 기본 위치(Root Position), 3음이면 1전위, 5음이면 2전위, 7음이면 3전위입니다. 위쪽 음들의 순서나 옥타브는 전위를 바꾸지 않습니다 — 그것은 다음 절의 '보이싱'입니다.

바로크 시대의 건반 주자들은 베이스 선율 위에 숫자만 보고 화음을 즉흥으로 채웠습니다. 이 숫자저음(Figured Bass, Basso Continuo)의 숫자는 '베이스 위 몇 도에 음이 있는가'를 적은 것이고, 지금도 화성학의 전위 표기로 쓰입니다. 오늘날 대중음악은 같은 정보를 슬래시 코드(Slash Chord) "C/E"(C 화음, 베이스 E)로 씁니다.

텐션: 9, 11, 13과 피해야 할 음

7화음 위에 3도를 계속 쌓으면 9·11·13음이 나옵니다. 재즈와 현대 대중음악은 이 음들을 텐션(Tension)이라 부르며 색채를 더하는 데 씁니다. 하지만 아무 텐션이나 더할 수는 없습니다. 실용 규칙은 하나로 요약됩니다.

회피음 규칙 화음음(1·3·5·7)보다 단9도(반음 + 옥타브) 위에 놓이는 텐션은 그 화음음과 강하게 충돌해 화음의 정체를 흐린다 — 피해야 할 음(avoid note). 예외: 속7화음의 ♭9(근음 위 단9도)는 도미넌트 특유의 긴장으로 받아들여진다.

상부 구조 3화음(Upper Structure Triad)은 텐션을 체계적으로 고르는 재즈 기법입니다. C7의 3음·7음(E, B♭) 위에 D 장3화음(D–F♯–A)을 얹으면 9·♯11·13이 한꺼번에 생겨 C13(♯11), 즉 리디안 도미넌트의 소리가 됩니다. 두 화음을 겹친 폴리코드(Polychord)로 보고 \(\frac{\text{D}}{\text{C7}}\)처럼 분수로 적기도 합니다.

보이싱: 같은 화음, 다른 배치

보이싱(Voicing)은 화음의 피치 클래스를 실제 음높이(옥타브와 순서)에 배치하는 방법입니다. 집합은 같아도 소리의 두께·밝기·탁함이 크게 달라지고, 화음과 화음을 잇는 성부 진행(9장)이 매끄러운지도 보이싱이 결정합니다. 주요 보이싱은 간단한 변환 규칙으로 정의됩니다.

저음역 음정 한계(Low Interval Limit, LIL)는 편곡의 경험칙입니다. "장3도는 B♭2보다, 단3도는 C3보다 아래에서 쓰지 말라." 이유는 6장의 임계대역에 있습니다. 같은 음정이라도 낮은 음역에서는 두 음의 주파수 차이 \(\Delta f\)가 절대값으로 작아져, 귀의 임계대역(저음역에서 약 100 Hz) 안에 함께 들어갑니다. 플롬프–레벨트 곡선에 따르면 거칠기는 \(\Delta f\)가 임계대역의 약 25%일 때 최대입니다.

$$\frac{\Delta f}{\mathrm{CB}(\bar f)},\qquad \mathrm{CB}(f) \approx 25 + 75\left[1 + 1.4\left(\tfrac{f}{1000}\right)^2\right]^{0.69}\ \text{Hz}\quad(\text{Zwicker})$$
예: C3(130.8 Hz)–E3(164.8 Hz) 장3도는 \(\Delta f = 34\) Hz, CB ≈ 101 Hz → 0.34 CB로 거칠기 최대 부근. 같은 장3도를 C5–E5로 올리면 \(\Delta f = 136\) Hz, 평균 주파수 591.25 Hz에서 CB ≈ 123.73 Hz → 1.10 CB로 깨끗하다. 그래서 피아노 왼손은 낮은 음역에서 근음+5도(또는 옥타브)를, 3도는 위쪽에 둔다 — 배음열(1:2:3:4:5…)이 아래는 넓고 위는 좁은 것과 같은 모양이다.

코드 기호와 이름 붙이기 알고리즘

코드 기호는 '근음 + 품질 + 텐션 + /베이스'라는 압축 표기입니다(Cm7♭5/G·G7(♭9,♭13)·Dsus4). 사람이 악보의 음 덩어리에 이름을 붙이는 일은 사실 역문제입니다. 같은 피치 클래스 집합에 여러 이름이 가능하기 때문입니다. {A, C, E, G}는 Am7이자 C6/A이고, {C, E♭, G♭, A}는 Cdim7·E♭dim7·G♭dim7·Adim7 모두입니다(대칭). 그래서 화음 인식 프로그램은 대개 다음과 같은 탐색 + 점수 구조를 씁니다.

  1. 후보 생성: 입력 음의 각 피치 클래스를 근음 후보 \(r\)로, 사전의 각 품질 \(q\)(구간 집합 \(Q_q\))와 짝지어 \(C_{r,q} = \{r + x \bmod 12 : x \in Q_q\}\)를 만든다.
  2. 정합 계산: 입력 집합 \(S\)와 비교해 빠진 음 \(C\setminus S\)과 남는 음 \(S\setminus C\)를 센다.
  3. 점수: 남는 음이 있으면 탈락, 빠진 음은 감점(5음 생략은 흔하므로 적게), 복잡한 화음은 소폭 감점(오컴의 면도날), 베이스가 근음이면 가점. 동점은 단순한 이름을 택한다.
$$\text{score}(r,q) = 10 - 4\,|\text{missing}|_{\neq 5} - 1\,|\text{missing}|_{=5} - 0.6\,(|Q_q| - 3) + 2\,[r = \text{bass}] - \epsilon_q$$
MB.detectChord가 실제로 쓰는 점수 식(\(\epsilon_q\): sus·aug·dim7·6화음 같은 '모호한' 품질에 주는 작은 감점). 실제 소프트웨어는 여기에 조성 맥락(이 조에서 흔한 화음인가), 앞뒤 화음, 음의 길이·세기를 확률 모델로 더한다. 결국 화음 인식은 사전(prior) × 정합도(likelihood)의 최대화 문제다.

피치 클래스 집합론: 화음의 동치류

음악 이론가 앨런 포르테(Allen Forte, 『The Structure of Atonal Music』 1973)는 무조 음악을 분석하려고 화음을 '이름' 대신 집합의 동치류로 분류했습니다. 두 집합이 이조(\(T_n\))나 전회 후 이조(\(T_nI\))로 서로 바뀌면 같은 집합류(Set Class)입니다. 이 군 \(\{T_n, T_nI\}\)는 원소가 24개인 이면체군 \(D_{12}\)이고, 집합류는 그 궤도(orbit)입니다.

각 집합류의 대표를 기본형(Prime Form)이라 하며 알고리즘으로 정의됩니다.

  1. 집합을 정렬하고 모든 회전을 만든다(각 원소를 맨 앞에 둔 순열). 첫 음을 0으로 옮긴다.
  2. 같은 일을 전회한 집합(\(-x \bmod 12\))에도 한다. 후보는 \(2n\)개.
  3. 마지막 원소(폭)가 가장 작은 후보를 고른다. 동점이면 오른쪽에서 두 번째 원소가 작은 것 → 세 번째… (Rahn 방식). 포르테 원래 방식은 왼쪽부터 비교하며, 5-20·6-Z29·6-31·7-Z18·7-20·8-26 여섯 집합류에서만 결과가 다르다.

포르테 번호 "4-27"은 '4음 집합류 중 27번째'라는 목록 번호입니다. 보수 관계인 집합류는 같은 번호를 가집니다(5-35의 보수가 7-35 = 다이아토닉). 'Z'가 붙은 쌍(4-Z15 / 4-Z29 등)은 음정 벡터가 같은데 집합류가 다른 경우로, 둘 다 ⟨1,1,1,1,1,1⟩, 즉 모든 음정을 한 번씩 갖는 '전음정 4화음'입니다.

$$\binom{12}{3} = 220 = \sum_{\text{집합류 } c} |\mathrm{orbit}(c)|,\qquad |\mathrm{orbit}(c)| = \frac{24}{|\mathrm{Stab}(c)|}$$
궤도–안정자 정리. 장3화음(3-11)은 대칭이 없어 궤도 크기 24(장3화음 12개 + 단3화음 12개), 증3화음(3-12)은 안정자가 6개라 궤도 크기 4. 번사이드 보조정리로 세면 3음 집합류는 12개, 4음은 29개, 5음은 38개다(아래 시뮬레이터가 직접 센다).

패드는 이 페이지가 \(2^{12}\)개 집합을 전수 조사해 찾은 집합류를 포르테 순서로 늘어놓은 것입니다(보라 글씨 = MB.CHORDS의 화음과 같은 집합류). 패드를 누르면 기본형(실선)과 그 전회형(점선)을 원에 그리고 차례로 들려줍니다 — 장3화음 ↔ 단3화음, 속7 ↔ 반감7처럼 '거울상' 화음의 짝을 들어 보세요. 이조 슬라이더는 원 위의 집합을 돌립니다(소리도 이조). 오른쪽 '검증'은 모든 집합류의 궤도 크기 합이 \(\binom{12}{n}\)과 같은지 확인합니다.

3도 밖의 화음: sus, 4도 쌓기, 폴리코드

  • sus 화음(Csus4 = C F G, Csus2 = C D G): 3음 대신 4음이나 2음을 써서 장·단을 정하지 않는다. sus4와 sus2는 같은 집합류 3-9(027)이며, Csus2의 음을 G부터 읽으면 Gsus4다. 7sus4(C F G B♭)는 속7의 회피음 11을 '3음을 빼서' 합법화한 형태로, 현대 재즈·가스펠에서 V 대신 자주 쓰인다.
  • 4도 쌓기(Quartal Harmony): 완전4도를 쌓은 C–F–B♭–E♭. 3-9·4-23(0257)처럼 5도 사슬의 연속 구간이라 5음음계의 부분집합이다. 근음이 모호하고 '열린' 소리가 나서 맥코이 타이너, 빌 에반스(마일스 데이비스 「So What」의 보이싱: 4도 셋 + 장3도)가 즐겨 썼다.
  • 폴리코드·상부 구조: 두 화음을 위아래로 겹친 것(3절 그림 8-3). 집합으로 보면 6–7음 집합이고, 이름은 '아래 화음 + 텐션'으로 읽는 것이 보통이다.
  • 클러스터: 반음·온음을 빽빽이 쌓은 화음(3-1 = 012). 집합론에서는 그냥 하나의 집합류이지만, 음향적으로는 거칠기가 가장 큰 화음이다(6장).
화음 수의 폭발과 '이름 있는 화음' 12음에서 고를 수 있는 3–6음 화음은 \(220 + 495 + 792 + 924 = 2431\)개(피치 클래스 집합 기준)이고, 집합류로 묶으면 12 + 29 + 38 + 50 = 129개다. 코드 기호 체계가 이름을 붙인 것은 이 중 3도 쌓기에서 나오는 일부일 뿐이다. 나머지는 무조 음악과 현대 재즈의 영역이며, 그곳에서는 포르테 번호와 음정 벡터가 이름 역할을 한다.

핵심 정리

  1. 3도 쌓기에서 3화음은 장3도·단3도 두 칸의 조합(\(2^2=4\)종: 장·단·감·증), 7화음은 세 칸의 조합(실제 7종)이다.
  2. 전위는 '무엇이 베이스인가'다. 숫자저음은 베이스 위 일반 음정을 적고(6, 6/4, 6/5, 4/3, 4/2), 대중음악은 슬래시 코드(C/E)로 쓴다. 2전위는 베이스 위 완전4도 때문에 불안정하다.
  3. 텐션은 화음음의 단9도 위에 오면 회피음이다(예외: 속7의 ♭9). 텐션 조합은 그 화음 위의 음계를 암시한다.
  4. 보이싱은 집합을 음높이에 배치하는 일이다. 드롭 2·3, 셸, 루트리스는 간단한 변환 규칙이다. 낮은 음역의 좁은 음정은 임계대역 안에서 거칠어지므로(LIL) 아래는 넓게, 위는 좁게 쌓는다.
  5. 화음 이름 붙이기는 '근음 후보 × 품질 사전'의 탐색과 점수 매기기이며, 같은 집합에 여러 이름이 가능하다(Am7 = C6/A, 감7의 대칭).
  6. \(T_n\)/\(T_nI\) 동치류가 집합류이고, 기본형과 포르테 번호로 대표한다. 220개의 3음 집합은 12개 집합류, 495개의 4음 집합은 29개 집합류로 묶인다.

확인 퀴즈

근음 위에 단3도 + 단3도 + 장3도를 쌓은 7화음은?

0 → 3 → 6 → 10: 단3화음 대신 감3화음(0 3 6) 위에 단7도(10)를 얹은 반감7화음이다. 감7은 단3도만 세 번(0 3 6 9), 속7은 장3도+단3도+단3도(0 4 7 10).

G7의 3전위에서 베이스 음과 숫자저음은?

G7 = G B D F. 3전위는 7음 F가 베이스이고, F 위로 G(2도), B(4도), D(6도)가 있어 6/4/2 → 약식 4/2(또는 2)다. 이 화음은 베이스 F가 반음 내려 E로 가며 C/E(I⁶)로 해결하는 것이 정석이다.

Cmaj7에서 피해야 할 텐션은 무엇이며, 그 이유는?

F는 E보다 반음(+옥타브) 위, 즉 단9도 위에 놓여 3음과 충돌하고 화음을 sus4처럼 흐린다. 장7화음 위에서는 리디안의 ♯11(F♯)을 쓴다.

C3–E3(장3도)가 C5–E5보다 탁하게 들리는 이유로 가장 알맞은 것은?

음정(주파수비)은 같아도 Δf는 음역에 비례한다. 임계대역은 저음역에서 거의 일정(~100 Hz)하므로 낮은 곳에서는 Δf/CB가 0.25 근처가 되어 플롬프–레벨트 거칠기가 최대에 가깝다. C5–E5는 Δf ≈ 136 Hz로 임계대역을 넘는다.

{A, C, E, G}에 대해 옳은 설명은?

A C E G = C E G A. 베이스가 A면 Am7, C면 C6로 부르는 것이 자연스럽다. 집합류는 4-26(0358). 4-27은 속7·반감7이다.

12개 피치 클래스에서 고른 3음 집합 220개는 이조·전회 동치로 몇 개의 집합류가 되며, 증3화음 집합류(3-12)의 궤도 크기는?

\(T_n/T_nI\) 동치류는 12개(이조만으로는 19개). 증3화음 {0,4,8}은 \(T_0, T_4, T_8\)과 세 개의 \(T_nI\)에 대해 불변이라 안정자 크기 6 → 궤도 24/6 = 4개(C·D♭·D·E♭ 위의 증3화음).
